# MDD-Shuttle

MDD Khatib Shuttle service — **STEL Shuttle Tracker** PWA.

🚌 Live site: **https://vasan-india.github.io/MDD-Shuttle/**

Track the shuttle bus between **Khatib MRT (Exit A)** and **Mandai Depot (MDD)**:

- Workday & Weekend/PH schedules
- Next-bus countdown with color-coded urgency
- Searchable timetable
- Dark mode
- Installable as a mobile app (PWA), works offline
